# Exercise: Hello World

## 🎯 Objective

Write your first programs to display messages on the screen and get comfortable with basic syntax.

## 📝 Problem 1: Classic Hello World

Write a program that prints "Hello, World!" to the screen.

### Requirements
- Use the `print()` function
- Output must match exactly: `Hello, World!`

### Expected Output
```
Hello, World!
```

---

## 📝 Problem 2: Personal Greeting

Write a program that prints three lines:
1. Your name
2. Your location
3. A message about learning to code

### Requirements
- Use three separate `print()` statements
- Each message should be on its own line
- Add a comment before each print statement

### Example Output
```
John Doe
New York, USA
I am excited to learn programming!
```

---

## 📝 Problem 3: ASCII Art

Create a simple ASCII art using multiple print statements. Get creative!

### Requirements
- Use at least 5 print statements
- Create a recognizable shape or pattern
- Add comments explaining your art

### Example Output
```
   ^
  / \
 /   \
/_____\
  | |
  | |
```

---

## 💡 Tips

1. Remember to use quotes around text: `"like this"`
2. Comments start with `#` in Python
3. Each `print()` statement adds a new line automatically
4. Test your code after each change
5. Don't worry about making mistakes - they're part of learning!

---

## 🧪 Testing Your Code

Run your program and check if:
- ✅ The output appears correctly
- ✅ There are no error messages
- ✅ The formatting looks as expected
- ✅ Comments explain what the code does
