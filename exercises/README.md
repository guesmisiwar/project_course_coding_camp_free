# Exercises

This directory contains coding exercises and challenges for practice.

## 🎯 Purpose

Exercises help reinforce concepts learned in the course materials through hands-on practice.

## 📁 Organization

Exercises should be organized to match the course structure:

```
exercises/
├── beginner/
│   ├── 01-hello-world/
│   │   ├── problem.md
│   │   ├── test-cases.md
│   │   └── starter-code/
│   └── 02-variables/
├── intermediate/
└── advanced/
```

## 📝 Exercise Format

Each exercise directory should contain:

1. **problem.md** - Problem statement
   - Clear description of the task
   - Input/output specifications
   - Constraints and requirements
   - Examples

2. **test-cases.md** - Test cases
   - Sample inputs and expected outputs
   - Edge cases to consider
   - Performance requirements (if applicable)

3. **starter-code/** - Optional starting templates
   - Basic structure to help students begin
   - Comments indicating where to add code

## 💡 Best Practices

- Start with simple exercises and gradually increase difficulty
- Provide clear, unambiguous problem statements
- Include multiple test cases
- Make exercises engaging and relevant
- Align exercises with course materials

## Contributing

When adding exercises:
- Test your exercise thoroughly
- Provide a solution in the solutions directory
- Include comprehensive test cases
- Consider multiple difficulty levels
